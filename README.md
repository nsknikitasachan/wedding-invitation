# Royal Blue & Gold Wedding Invitation

A responsive wedding invitation website for GitHub Pages. Includes a welcome screen, tap-to-open envelope, invitation card, live countdown, event cards and Google Maps directions.

## Step 1 — Edit your details
Open `config.js` in a text editor and replace the sample names, date, time, venue, map URL and event information.

For India, use a date/time like `2027-02-25T19:00:00+05:30` in `weddingDateTime`. Change the display date and weekday separately so they match.

Google Maps link example:
`https://www.google.com/maps/search/?api=1&query=Venue+Name+Kanpur`

## Step 2 — Preview locally
Double-click `index.html` to open it in a browser. If needed, use Visual Studio Code and its Live Server extension.

## Step 3 — Publish free on GitHub Pages
1. Sign in at https://github.com (create an account if needed).
2. Click **New repository**.
3. Name it `wedding-invitation`; choose **Public**; click **Create repository**.
4. In the repository, click **Add file → Upload files**.
5. Upload `index.html`, `style.css`, `config.js`, `script.js` and `README.md` (upload the files, not the containing folder).
6. Click **Commit changes**.
7. Open **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Choose branch `main` and folder `/ (root)`, then click **Save**.
10. Wait a few minutes. Your website URL will appear in Settings → Pages. It will look like `https://YOUR-USERNAME.github.io/wedding-invitation/`.

## Step 4 — Update later
Edit `config.js` directly on GitHub and commit your changes. GitHub Pages will redeploy automatically.

## Notes
GitHub Pages hosting is free. The published site is public, so avoid private phone numbers or sensitive personal details. Google Fonts requires an internet connection. A custom domain is optional.
